# 監造報表 pipeline 範例庫

收集「施工日誌→監造報表」端到端 pipeline 各步驟的輸入/輸出範例,供開發 SP0–SP4 對照與測試。
背景與拆解見專案記憶 `supervision-report-pipeline`。

## 資料夾對應

| 子夾 | 內容 | 格式 | 用於 |
|---|---|---|---|
| `決標公告/` | 決標公告(公文) | 固定 | SP1 審核基準 |
| `開工報告表/` | 廠商開工報告表 | **不固定** | SP1 被審核對象 |
| `發包經費總表/` | 內部發包經費總表 | 固定(待客戶給範例) | SP2 契約詳細價目表來源 |
| `施工日誌/` | 各家施工日誌/日報表 | 各家不同(每家一支讀取器) | SP3 每日施工紀錄來源 |
| `監造報表範本/` | 空白公版範本 + 已填實例 | .xlsm(含巨集) | 全流程填寫目標 |
| `公文/` | 廠商公文 + 我方公文 | 固定 | SP4 |
| `驗證清單/` | 施工日誌驗證檢查清單 | .xlsx | SP3 48 條驗證依據 |

## 版控政策

- **版控(小、spec 關鍵)**:`監造報表範本/監造報表_空白公版範本.xlsm`、`驗證清單/*.xlsx`、本 README。
- **不版控(大二進位)**:其餘原始範例(已填 .xlsm、pdf、docx、原始 xls)由 `.gitignore` 排除,只放本機供開發;需要當測試 fixture 時再挑代表性小檔複製進 `app/tests/fixtures/`。

## 關鍵事實

- 監造報表 .xlsm 是「自算活頁簿」:只需填 `工程基本資料`(9 值)、`契約詳細價目表`(項目)、`每日施工紀錄`(逐日本日完成數量)三區,其餘公式自動帶出。
- 寫入須保留巨集/公式→走 Excel COM(細節見記憶 `xlsm-excel-com-findings`)。

## 元方營造有限公司 — 古坑國中小(兩案兩檔,52 頁/檔)

`古坑國小施工日誌(115.07.15~115.07.31).pdf`／`古坑國中…pdf`。

### 頁面結構:**封面 1 頁 + 每天 3 頁**(52 = 1 + 17×3)

```
頁1        封面(承攬廠商簽章、月報標題),沒有錨點
頁2,5,8…   錨頁:「表報編號:N」+ header + 材料表          ← 每 3 頁一次
頁3,6,9…   明細「第 1 頁共 2 頁」
頁4,7,10…  明細「第 2 頁共 2 頁」
```

⚠️ **判填報日期一定要先把 items 依 y 由大到小排序**。`extractItems` 回傳的原始
順序不是視覺順序,直接 join 起來取「第一個日期」會抓到開工日期(每天都是 7/15),
看起來像「錨頁的日期停在 7/15、與明細頁對不上」——那是假象。排序後錨頁的
第一個日期就是填報日期,7/15→7/16→7/17 逐日遞增,與其後兩張明細頁完全對齊。
錨頁的三個日期依序是:**填報日期、開工日期(115/7/15)、完工日期(116/1/10)**。

## 明德土木包工業 — 東榮國中(兩案,每案兩聯**分成兩個 PDF 檔**)

2026-08-11。我拿兩個問題去問使用者(監造報表分頁要不要有貳~陸、兩張經費總表要產
幾份報表),他回「**不能看其他範例嗎?**」——**兩題都能從範例直接答出來,我只是
掃的範圍太窄。**

**Why**:這個專案幾乎每個「規格問題」都能用他既有的報表回答,而且證據比他的口頭
回答可靠(他寫「貳到陸一定要有」,但他自己 95 份報表 0 份有——口頭描述會漏掉
自己習以為常的前提)。拿掃不完整的樣本去問,等於要他做我能自己做的事。

**How to apply**:要問規格之前,先確認**範例掃完了沒有**。

## ⚠️ 監造報表範例不只 `模板\全案範例\`(那只有 49 份)

`%USERPROFILE%\OneDrive\Desktop\PMIS範例` 底下**遞迴**找 `*監造報表*.xlsm`
共 **122 份、去重後 95 份**,分三批:

| 位置 | 內容 |
|---|---|
| `模板\全案範例\<案>\` | 49 份,**附完整原始文件**(決標公告/經費總表/施工日誌)——要端到端對帳只能用這批 |
| `模板\監造報表\` | 約 35 份,**只有報表**沒有原始文件 |
| `監造報表\`(根目錄) | 約 28 份,與上一批大量重複 |

**要驗「版面慣例」用 95 份那個母體**(檔名去重);
**要驗「讀取器準不準」只能用 49 份那批**(其餘沒有原始文件可跑)。

## 那兩題的答案(都是查出來的)

**① 監造報表分頁不列費用項目。** 95 份**沒有一份**在監造報表分頁出現貳~陸(0/95)。
第 23 項的「貳到陸一定要有」指的是**契約詳細價目表**,不是那個分頁。
(那一頁是給人看施工進度的,職安衛管理費與營業稅沒有施工進度可言。)

**② 一張決標、兩個標的 → 產兩份分開的報表。** 既有慣例,實例:

```
重興汙水  812,102 (18 項) + 重興廁所  871,943 (32 項) = 1,684,045 = 決標金額
橋頭(許厝分校) 2,679,146 (33 項) + 橋頭(橋頭國小) 1,670,374 (33 項)
古坑國小 / 古坑國中、東榮國小 / 東榮國中 也是同一個模式
```

現在的 `selectSheets` 是「合計等於決標金額就合併成一份」,與此不符(第 24 項)。

2026-08-07,拿 [[truth-dataset-49-cases]] 的人工監造報表當外部基準跑
`app/scripts/check-against-truth.js`,48 案 × 5 欄。

**Why**:這兩個 bug 都是「輸出格式合法、內容錯」,舊的驗收方式（拿讀取器自己的輸出當基準,
見 [[parser-pipeline-gaps]]）**結構上不可能抓到**。是外部基準才看得見。

## 修掉的兩個

1. **值換行的續行被丟掉**（4 案工程名稱被截斷）。`firstValue` 只處理「標籤」換行
   （續行無值）,沒處理「值」換行（續行 `label===''`、value 是後半段）。
   新增 `valueWithContinuation`,只用於標案名稱。
2. **比對層缺 NFKC**。決標公告的文字在 `pdf.js` 已折過全形,主檔的值是人打的常留全形。
   同型問題 SP3 的 `daily-log-validate` 已於 `454ba35` 修過,SP1 這層當時漏了。

## ⚠️ 「續行一律接回來」是災難級修法

48 案實測:**「總決標金額」後面 46/46 都接一列 `label===''` 的國字大寫金額**
（`1,070,000元` → 下一列 `壹佰零柒萬元`）。那是**另一個欄位**,不是續行。
接回來會讓值變成 `1,070,000元壹佰零柒萬元`,`parseAmount` 回 null,
**每一案的契約金額都變成讀不到**。

全檔統計:48 案共 2355 個 `label===''` 且 value 非空的列。全面接回來會全毀。
`標案名稱` 後接空 label 有值的只有 4/46（全是真續行）;`機關名稱`/`標案案號` 是 0/46。
測試已釘住金額那條護欄。

## 剩下 5 筆不一致（都不是讀取器該改的）

- **溝壩鋪面**:公告寫的名稱本來就比人工報表短（少 `公立中小學校園環境安全改善計畫-`）。
  已查原始 PDF 確認**沒有續行**——是文件本身不同,不是 bug。
- **聖隆營造 ×2**:讀取器讀到 `聖隆營造有限公司 (Shenglong Construction Co., Ltd.)`,
  人工填時去掉英文。屬「要不要去尾」的規則問題。
- **契約金額 ×2**:`D11313公誠育英樓排水` 答案卷 8901687 / 讀取器 891687;
  `永慶114運動場` 答案卷 31507 / 讀取器 357135。**需要看原始公告才能判誰對**,
  第二筆很可能是答案卷打錯。

## 還沒查

- **饒平、元長 2 案**:`parseAwardNotice` 沒 throw 但 5 欄全空,疑為非「友善列印」版面。
- `D11411鹿場鋪面` 的決標公告是掃描件,讀取器正確報錯（不是 bug）。
